1.3 Client-Server Architecture

The web follows a Request-Response cycle:

  1. User types URL in browser
  2. Browser queries DNS to convert domain → IP address
  3. Browser sends HTTP GET request to server IP
  4. Server processes request (possibly queries database)
  5. Server sends HTTP response (status code + HTML)
  6. Browser parses HTML, discovers CSS/JS files, makes additional requests
  7. Page fully rendered
💡 Key Definitions:
HTTP — HyperText Transfer Protocol (communication protocol) • DNS — Domain Name System (domain → IP) • URL — Uniform Resource Locator • IP Address — Unique numerical device address

3.2 Specificity

Specificity = (a, b, c): a = IDs, b = classes/attributes/pseudo-classes, c = types/pseudo-elements

* = 0,0,0 → div = 0,0,1 → .class = 0,1,0 → #id = 1,0,0 → inline style → !important

When specificity is equal, source order wins (last rule applies).

3.3 The CSS Box Model

Every element = Content → Padding → Border → Margin
Padding = space INSIDE the border • Margin = space OUTSIDE the border
Shorthand: padding: 10px 20px 15px 5px; (↑ → ↓ ←, clockwise)
Q: What does box-sizing: border-box do?
A: Makes width INCLUDE padding + border (not just content). Without it (content-box), total width = width + padding + border. Always use: *, *::before, *::after { box-sizing: border-box; }

Write Everything You Know About HTML5

📝 Question:

"Write a comprehensive and well-organized summary about HTML5 — the standard markup language for the web. Your answer should cover everything you have learned about this topic in the course, including but not limited to: what HTML is, document structure, elements, semantic tags, forms, tables, media, and best practices."
✅ Model Answer — Complete HTML5 Summary:

1. What is HTML & HTML5?

  • HTML = HyperText Markup Language — the standard markup language used to create and structure content on the web
  • HTML5 = the fifth and current major version of HTML (standardized in 2014 by W3C)
  • HTML is NOT a programming language — it's a markup language that describes the structure of a page using tags and elements
  • HTML5 introduced: semantic elements, native audio/video, Canvas API, local storage, geolocation, and form enhancements
  • Every web page you see in a browser is built with HTML as its foundation

2. Basic Document Structure

Every HTML5 document follows a standard structure:

<!DOCTYPE html>        <!-- Declares HTML5 to the browser -->
<html lang="en">           <!-- Root element, lang for accessibility -->
<head>                       <!-- Metadata (not visible) -->
  <meta charset="UTF-8">    <!-- Character encoding -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Page Title</title>  <!-- Browser tab title -->
  <link rel="stylesheet" href="styles.css">
</head>
<body>                       <!-- All visible content -->
  <h1>Hello World</h1>
  <script src="script.js"></script>
</body>
</html>
💡 Key Points:
• <!DOCTYPE html> must be the very first line — tells browser to use HTML5
• <head> contains metadata (title, charset, stylesheets) — not visible
• <body> contains all visible content
• lang="en" helps screen readers and search engines

3. HTML Elements & Tags

HTML uses tags (enclosed in < >) to define elements. Most elements have an opening and closing tag:

9. HTML Forms

Forms collect user input and send it to a server for processing:

<form action="/submit.php" method="POST">
  <!-- Text input with label -->
  <label for="name">Full Name:</label>
  <input type="text" id="name" name="name" required minlength="2">

  <!-- Email with validation -->
  <label for="email">Email:</label>
  <input type="email" id="email" name="email" required>

  <!-- Password -->
  <label for="pass">Password:</label>
  <input type="password" id="pass" name="password" minlength="8">

  <!-- Dropdown select -->
  <label for="city">City:</label>
  <select id="city" name="city">
    <option value="">Select...</option>
    <option value="cairo">Cairo</option>

  <!-- Radio buttons -->

  </fieldset>

  <label for="msg">Message:</label>

  <!-- File upload -->

11. Best Practices & Key Takeaways

✅ HTML5 Best Practices:

1. Always use <!DOCTYPE html> as the first line
2. Always include alt attribute on images (accessibility & SEO)
3. Use semantic elements — <header>, <nav>, <main>, <footer>
4. One <h1> per page — use heading hierarchy (h1 → h2 → h3)
5. Always pair form inputs with <label> using for/id
6. Use method="POST" for sensitive form data
7. Validate server-side — never rely only on client-side validation
8. Use lang attribute on <html> element
9. Tables for data only — never for layout
10. Keep code indented and clean — readability matters
📌 Summary: HTML5 is the backbone of every web page. It provides the structure (elements, tags), meaning (semantic elements), interactivity (forms, links), and media (images, video, audio) that make the web work. Combined with CSS for styling and JavaScript for behavior, HTML5 forms the essential foundation of modern web development.
